Tax Delivery Challan QWeb Report for Odoo 18
===========================================

Overview
--------
Enhance your Odoo inventory workflow with a professional Tax Delivery Challan report.
This module provides a fully customized QWeb-based challan format with company seal,
signature, and transport details, designed for Indian Tax compliance.

Features
--------
- Tax-compliant Delivery Challan format
- Custom QWeb report for stock picking
- Company Seal integration (image)
- Authorised Signature support
- Transport details:
  • Vehicle Number
  • Transporter Name
  • LR Number
- Clean and professional layout
- Amount in words (currency conversion)
- Multi-copy format:
  • Original for Consignee
  • Duplicate for Transporter
  • Triplicate for Consigner
- Fully compatible with Odoo 18

Benefits
--------
- Standardizes delivery challan across organization
- Saves time with automated report generation
- Improves compliance with Tax requirements
- Enhances document professionalism
- Reduces manual errors in documentation

Use Cases
---------
- Manufacturing companies
- Trading businesses
- Logistics & supply chain companies
- Tax-compliant invoicing workflows

Installation
------------
1. Copy the module to your Odoo addons directory
2. Update Apps list
3. Install the module from Apps menu

Configuration
-------------
- Go to Settings → Companies
- Upload:
  • Delivery Challan Seal
  • Authorised Signature
- Configure transport details in delivery orders (optional)

Usage
-----
- Go to Inventory → Delivery Orders
- Open any delivery
- Print Delivery Challan
- Customized Tax challan will be generated

Technical Details
-----------------
- Built using QWeb reporting engine
- Compatible with Odoo 18
- Depends on:
  • base
  • stock
  • sale
  • web
