This module provides a professionally designed Delivery Challan report in Odoo 18 with Tax compliance, including company seal and authorized signature. Module Installation

Go to the Apps section and search for 'Delivery Challan Pdf Report'. Select the module (mst_mems_stock_delivery_challan_qweb_report) and click Install. After installation, the feature is available in the Inventory module.

Print & Download

Open any delivery order and click Print, then choose 'Delivery Challan'. The report is generated instantly in QWeb PDF format with a clean layout and ready-to-use format. So that the custom report is efficiently used for sale delivery orders by the end users.

Report Details

The Delivery Challan report includes delivery number, date, customer details, TAXIN, and address information. It also shows product details such as item name, quantity, UOM, and total amount. Multiple copies like Original, Duplicate, and Triplicate are clearly mentioned for compliance. The report contains sections for Authorised Signatory and Seal, ensuring proper validation and official approval.
