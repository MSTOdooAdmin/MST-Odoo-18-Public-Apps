Sales Order Summary Report (QWeb PDF)
====================================

Overview
--------
Upgrade your Odoo sales workflow with a professional Sales Order Summary Report.

This module provides a clean, structured, and business-friendly PDF format
for Sales Orders and Quotations. Designed for clarity and efficiency, it
enhances customer communication and ensures consistent reporting.

Features
--------
- Professional Sales Order PDF layout
- Clean and modern design
- Customer details with complete address
- Product table with quantity, rate, discount, and subtotal
- Automatic total and tax calculation
- Amount in words
- Company branding (logo, address, contact details)
- Footer with signature, seal, and terms
- A4 optimized print format
- Easy to customize

Benefits
--------
- Improves sales document quality
- Saves time with automated reporting
- Reduces manual errors
- Enhances customer communication
- Provides professional business documents

Use Cases
---------
- Sales teams
- Quotations and order confirmations
- Manufacturing companies
- Trading businesses
- SMEs and enterprises using Odoo

Installation
------------
1. Copy the module to your Odoo addons directory
2. Update the Apps list
3. Install the module from Apps menu

Configuration
-------------
- No additional configuration required
- Report will be available in Sales Orders

Usage
-----
- Go to Sales → Orders → Quotations / Sales Orders
- Open any record
- Click Print → Sales Order Summary Report

Technical Details
-----------------
- Odoo Version: 18.0
- Report Type: QWeb PDF
- Dependencies:
  - sale
  - mail
