CRM Lead Sequence Number Generation by Source

Streamline lead management with Odoo CRM Sequence by Source. This module automatically generates lead reference numbers based on the selected lead source, using configurable source-wise prefixes such as Search Engine, LinkedIn, Facebook, Newsletter, and more. It improves lead tracking, organizes CRM records clearly, and helps teams identify lead origin quickly for better reporting and follow-up.

1. Lead Source Prefix Configuration

Configure a unique prefix code for every lead source in CRM, such as Search Engine, LinkedIn, Facebook, Newsletter, or other marketing channels. Each source can have its own reference code like SE, IN, FB, or NL to support clear and organized lead numbering. This setup helps standardize lead records and gives businesses better visibility into where each opportunity is coming from.

2. Lead Creation with Source Selection

During lead creation, users simply select the source from the CRM dropdown list. Based on the chosen source, the system automatically picks the configured prefix and applies the correct sequence logic. This makes lead entry faster, more accurate, and fully aligned with source-based tracking.

3. Automatic Lead Sequence Generation

Once the lead is saved, the module automatically generates a lead reference number using the configured source prefix. For example, a LinkedIn lead can be created as IN00001, while a Facebook lead can follow its own numbering pattern. This improves lead organization, supports source-wise reporting, and makes CRM records easy to identify, track, and manage.
