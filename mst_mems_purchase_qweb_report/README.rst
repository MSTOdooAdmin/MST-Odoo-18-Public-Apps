Purchase Order Summary Report (QWeb PDF)
=======================================

Overview
--------
Upgrade your Odoo purchase workflow with a professional Purchase Order Summary Report.
This module provides a clean, structured, and business-friendly PDF format for purchase orders.

Designed for clarity and efficiency, it enhances vendor communication and ensures
consistent reporting across your organization.

Features
--------
- Professional Purchase Order PDF layout
- Clean and modern design
- Vendor details with complete address
- Product table with quantity, rate, and subtotal
- Automatic total calculation
- Tax and final amount display
- Amount in words
- Company branding (logo, address, contact)
- Footer with user, date, and page numbers
- A4 optimized print format
- Easy to customize

Benefits
--------
- Improves purchase document quality
- Saves time with automated reporting
- Reduces manual errors
- Enhances vendor communication
- Provides professional business documents

Use Cases
---------
- Procurement teams
- Purchase departments
- Manufacturing companies
- Trading businesses
- SMEs and enterprises using Odoo

Installation
------------
1. Copy the module to your Odoo addons directory
2. Update the Apps list
3. Install the module from Apps menu

Configuration
-------------
- No additional configuration required
- Report will be available in Purchase Orders

Usage
-----
- Go to Purchase → Orders
- Open any Purchase Order
- Click Print → Purchase Order Summary Report

Technical Details
-----------------
- Odoo Version: 18.0
- Report Type: QWeb PDF
- Dependencies:
  - purchase
  - mail
