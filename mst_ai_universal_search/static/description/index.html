AI Universal Search

AI Universal Search is a powerful Odoo module that revolutionizes how you find records. Simply type your query with the "ai:" prefix in the standard Odoo search bar, and the module uses OpenAI ChatGPT or Anthropic Claude to intelligently convert natural language into precise Odoo search domains.


No more complex filters or manual domain building — just natural, conversational search that works seamlessly across all list views in modules like HR, CRM, Sales, Inventory, Accounting, and more. Fast, smart, and fully native — making data access effortless for every user. Compatible with Odoo 18.

Frequently Asked Questions

Does this module support Odoo 18?

Yes, the module is fully compatible with Odoo 18 Community and Enterprise editions.

Which AI providers are supported?

Currently, the module supports OpenAI ChatGPT and Anthropic Claude AI.

How do I use AI Search?

Simply type your search query in the native Odoo search bar with the ai: prefix.

Do I need an OpenAI or Claude API Key?

Yes. To use AI-powered search, you must configure a valid OpenAI ChatGPT API Key or Anthropic Claude API Key in the AI Provider configuration.

Can I configure multiple AI providers?

Yes. You can configure both OpenAI ChatGPT and Claude AI, and choose which provider to use for each search.
