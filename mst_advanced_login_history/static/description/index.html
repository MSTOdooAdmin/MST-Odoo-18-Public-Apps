Frequently asked questions

Login history and user audit FAQ

What does Login History track?

Logins, logouts, failed attempts, session details, devices, available locations and configured record actions.

Does it include a dashboard?

Yes. Review session indicators, recent activity, failed attempts and the latest available login location.

Can I choose which models to audit?

Yes. Select models and enable create, modify or delete tracking in Model Log Configuration.

Can I compare old and new values?

Yes. Model Logs display the field values available for recorded changes and link to the related record.

Does location tracking require permission?

Precise browser coordinates require location permission. Available location details depend on the data provided.
