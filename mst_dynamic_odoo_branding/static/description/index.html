Odoo branding & debranding FAQ

What does Dynamic Brand Identity Suite for Odoo change?

It replaces the Odoo name in the browser tab, the “Powered by Odoo” text on the login page and the /odoo part of backend URLs with your own brand. It can also hide the Manage Databases link.

Does it modify Odoo core files?

No. The module uses standard Odoo template and asset extensions rather than changes to core files. Use the module version that matches your Odoo release when planning an upgrade.

Will old /odoo links still work after I set a URL prefix?

Yes. Links in emails, chatter messages and existing bookmarks keep working. After the page opens, the address bar shows your prefix instead of /odoo.

Can I choose any word as the URL prefix?

Any name of 2 to 40 letters, digits, hyphens or underscores, as long as Odoo does not already use it. Names such as odoo, web, shop or my, and names of existing Odoo pages, are refused when you save.

Who can change the branding settings?

Only Odoo administrators. The Dynamic Branding section in Settings is not visible to other users.

How do I go back to the standard Odoo look?

Clear the URL Prefix to restore /odoo URLs. Clear Dynamic Brand Name to use the company-name fallback. Adjust Powered By Text to the wording you want, tick Show Manage Databases to show the link, then save and reload.

Does hiding Manage Databases restrict database administration?

This setting controls the visibility of the link on the supported pages. Database administration access must still be managed through your Odoo deployment configuration.
