Frequently Asked Questions

1. What does the Field Highlight Widget do?

It adds configurable visual highlighting to supported Odoo fields using XML options without changing the stored field value.

2. Can I use my own color codes?

Yes. You can use direct hex color codes such as #198754 or #DC3545. The widget automatically chooses readable text for direct hex backgrounds.

3. Can the color change based on the field value?

Yes. Use value_colors to map technical values such as draft, confirmed, done or cancel to different colors.

4. Does it support conditional highlighting?

Yes. The widget supports always, equal, not equal, contains, empty, greater, less, in, not in and related comparison operators.

5. Can I use it with the Odoo statusbar?

Yes. Set base_widget to statusbar. The widget highlights only the current state and preserves the statusbar_visible sequence declared in XML.

6. Does this module add menus or configuration records?

No. It is a developer-only frontend widget. Configuration is done directly in XML view definitions.
