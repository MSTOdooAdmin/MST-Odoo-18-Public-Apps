Project Default Task Stages
===========================

Overview
--------
Boost your Odoo project workflow with automated default task stages.
This module helps standardize task pipelines, improve project efficiency,
and simplify project management in Odoo 19.

Features
--------
- Configure default task stages for Odoo projects
- Automate project workflow with predefined task stages
- Standardize task pipeline across all projects
- Improve project tracking and workflow visibility
- Seamless integration with Odoo Project module
- Compatible with timesheets and sales integration
- Clean and user-friendly interface
- Fully compatible with Odoo 19

Benefits
--------
- This module is ideal for businesses looking for Odoo project workflow automation
and standardized task stage management.
- Saves time during project setup
- Ensures consistency across teams
- Reduces manual errors in stage configuration
- Improves project tracking and reporting

Use Cases
---------
- Organizations managing multiple projects
- Teams needing standardized workflows
- Businesses looking to improve project efficiency

Installation
------------
1. Copy the module to your Odoo addons directory.
2. Update the Apps list.
3. Install the module from the Apps menu.

Configuration
-------------
- Navigate to Project settings
- Define default task stages
- Apply configurations as needed

Usage
-----
- Create a new project
- Default stages will be applied automatically
- Manage tasks using predefined workflow stages

Technical Details
-----------------
- Compatible with Odoo 19
- Depends on:
  * project
  * mail
  * base
